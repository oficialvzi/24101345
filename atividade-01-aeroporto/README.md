## 3. Dados indispensáveis (10)
1. Passaporte dos passageiros
    - Essencial pois é um identificador único internacional para cada pessoa.
2. Número dos voos
   - Essencial pois identifica cada voo.
3. Origem dos voos
   - Essencial para saber a origem do voo.
4. Destino dos voos
   - Essencial para saber o destino do voo.
5. Portão dos voos
   - Essencial para os passageiros saberem onde ir para pegar o seus voos, e os pilotos das aeronaves saberem onde estacionar as aeronaves de modo organizado.
6. Horário de partida dos voos
   - Essencial para saber quando os voos saem de certo local.
7. Horário de chegada dos voos
   - Essencial para saber quando os voos chegam em certo local.
8. Número de passageiros da aeronave
   - Essencial para saber o número máximo de passageiros em uma aeronave (assim não fazendo uma superlotação)
9.  ID das bagagens
    - Essencial pois é um identificador único para cada bagagem, assim podendo distinguir cada bagagem umas das outras.
10. Capacidade máxima da aeronave
    - Essencial para saber a capacidade máxima (peso) de uma aeronave para assim não superlotar e causar um risco aos passageiros.
